# Story Format

Use this exact format for every generated user story.

```md
**As a** [specific user type], **I want to** [specific action] **so that I can** [clear benefit].

**Pre-conditions:**
- [Condition that must be true before the user can begin this flow]
- [System state, permission, or data requirement]
- [Any prior step or setup required]

**Acceptance Criteria:**
- [Specific, testable criterion]
- [Field-level validation, if relevant]
- [Success path behavior]
- [Failure path behavior]
- [Edge case]
- [Permission or access rule]
- [System state change]

**Post-conditions:**
- [State of the system after successful completion]
- [Notification, email, or audit log created, if relevant]
- [Record updated, created, deleted, or left unchanged]
```

Do not add sections before or after this structure unless the user explicitly asks.
